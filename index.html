Check our work

We sign every CBOM we publish with ML-DSA-65 (FIPS 204). Download one, download our public key and check it offline — we are not asking you to take our numbers on trust.

git clone https://github.com/SarthakShrivastav-a/ecdat && cd ecdat && pip install -e .
curl -O https://sarthakshrivastav-a.github.io/ecdat/ecdat-mldsa65.pub
ecdat verify cbom.json --pubkey ecdat-mldsa65.pub

How to read our numbers

We scanned each repository's default branch as we downloaded it on 18 Sep 2026. Observed means we found it in the project's own code, configuration, certificates or binaries; an algorithm a dependency merely could provide we list separately and never count as use. For the snapshot we make two browser-equivalent connections per site and publish only sector totals. Quantum-year Z is an assumption you set, not a forecast we are making.
